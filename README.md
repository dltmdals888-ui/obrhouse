# 오브하우스 시작 페이지

오브하우스 운영 페이지(구글 앱스 스크립트)를 이 페이지 안에 끼워 넣어 엽니다.
폰 홈 화면에 추가하면 부엉이 아이콘이 됩니다 (앱스 스크립트는 아이폰 아이콘을 정할 수 없어서).

- 비밀·직원 정보·가게 데이터는 없습니다.
- 내 입장권은 주소의 # 뒤(GitHub로 안 감)와 이 페이지 저장칸(그 기기·그 앱에만)에 둡니다. 홈 화면 앱은 manifest의 시작 주소(# 없음)로 열려서 저장칸 입장권으로 들어갑니다. 나가면 지웁니다.
- 폰 알림(OneSignal 웹 푸시): `index.html`의 `PUSH.appId`(공개 값)가 있을 때만 켜집니다. 서비스 워커는 `push/onesignal/`에만 있습니다. 비밀 키(REST API 키)는 여기 두지 않습니다.
- 운영 페이지는 이 주소 안에서만 끼워 넣어 열리게 되어 있습니다.
